# Simple React + Tailwind CSS Project

A lightweight React application built with Vite and Tailwind CSS for a modern landing page style interface. The project includes a navigation bar, hero section, feature cards, task preview panel, and footer layout.

## Project Overview

This app is designed as a simple front-end starter project to showcase:

- React component-based architecture
- Tailwind CSS styling
- Responsive layout sections
- Task-related mock data and preview cards
- Vite development workflow

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- ESLint

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

The app will run in the browser using the local Vite development server.

### 3. Build for production

```bash
npm run build
```

### 4. Preview the production build

```bash
npm run preview
```

## Available Scripts

```bash
npm run dev     # start the development server
npm run build   # create a production build
npm run preview # preview the production build locally
npm run lint    # run ESLint checks
```
